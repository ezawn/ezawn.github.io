Octavia is a four-key rhythm game that runs in the browser, in the style of osu!mania. Notes fall down four lanes and you press the matching key as each one crosses the hit line. I built it as my A-level Computer Science coursework project.

The code is on [GitHub](https://github.com/ezawn/Octavia).

## What it does

- Four-lane gameplay drawn on an HTML5 canvas, played with `D` `F` `J` `K`.
- Each key press is graded GREAT, GOOD, OK, MEH or MISS by how close it lands to the note's ideal hit time.
- Every chart is worth 1,000,000 points for a perfect run, and a finished chart is graded from SS down to F.
- Multiplayer rooms let you share a room code, chat in the lobby and start the same chart for everyone.

## How it is built

The game is written in vanilla JavaScript, with a Node.js, Express and Socket.IO server.

**Timing.** A note's position is calculated from timestamps, not from a frame count, so notes move at the same speed whatever the frame rate. Each note stores the moment it should cross the hit line, and a key press is judged by how many milliseconds it lands from that moment.

**Scoring.** Each note's base score is multiplied by `1 + (current combo / total notes)`, so holding a combo makes later notes worth more. The total is then scaled so that a full combo of GREATs on any chart comes to exactly 1,000,000, which makes scores comparable between charts of different lengths.

**Multiplayer.** The server keeps a list of rooms in memory. Clients send events to join a room, send a chat message or pick a chart, and the server passes each one on to everyone else in the room.

## What I would add next

- **Audio.** Charts are timed note patterns without a backing track, so syncing notes to music is the main thing missing.
- **Live scores.** The server can already relay each player's score, but the game does not send it yet.
- **Hosting.** The client connects to a local server, so it needs a configurable address before it can go online.
